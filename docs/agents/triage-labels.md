# Labels de triagem

Os skills falam em cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis para os labels usados de fato no tracker deste repo.

| Label em mattpocock/skills | Label no nosso tracker | Significado                                   |
| -------------------------- | ---------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`         | O mantenedor precisa avaliar a issue          |
| `needs-info`               | `needs-info`           | Aguardando mais informações de quem abriu     |
| `ready-for-agent`          | `ready-for-agent`      | Totalmente especificada, pronta para um agente |
| `ready-for-human`          | `ready-for-human`      | Precisa de implementação humana               |
| `wontfix`                  | `wontfix`              | Não será feita                                |

Quando um skill mencionar um papel (ex.: "apply the AFK-ready triage label"), use o label correspondente desta tabela.

Edite a coluna da direita se o vocabulário do repo mudar.
