# UX do MasterMail

> Princípios e fluxos. Vocabulário conforme `CONTEXT.md`. Escrito em 2026-10-13 depois do primeiro uso real; é a referência para as telas daqui em diante.

## Princípios

1. **Teclado primeiro, mouse sempre possível.** Toda ação tem tecla. Toda tecla aparece no menu e na paleta `⌘K`. `?` mostra a tabela de atalhos.
2. **Nunca uma janela modal para o que é rotina.** Responder, mover, adiar e buscar acontecem no lugar, sem sheet. Modal só para o que é raro (configurações, confirmar remoção de participante).
3. **A Caixa de entrada é fila, não arquivo.** O objetivo de cada item é sair dela: respondido, arquivado, em Pasta local ou adiado. Depois de uma ação, o foco vai para o próximo item sozinho.
4. **Cada ação tem desfazer.** Toast discreto no rodapé: "Arquivada · desfazer (z)". Nada pergunta "tem certeza?".
5. **Nativo e denso.** Três colunas do macOS, sem chrome próprio, fonte do sistema, linhas compactas. A informação nova (não lida, Ramo, Importante) é o único lugar com cor.
6. **IA aparece como texto, não como botão.** Justificativa e Sugestão são uma linha cinza no cartão; aceitar é uma tecla. Com a IA desligada, a linha não existe.

## Mapa da janela

```
┌ Barra: [Mail | Calendário | Pessoas]   busca (/)   ⌘K ┐
├──────────┬──────────────────────┬─────────────────────┤
│ Conta    │ Lista                │ Conversa            │
│  Caixa   │  remetente  · hora   │  assunto            │
│  Triagem │  assunto             │  ┌ mensagem 1       │
│  Enviados│  prévia · Categorias │  ├ ↳ mensagem 2     │
│  Rascun. │                      │  ├ ↳ mensagem 3 Ramo│
│  Arquivo │                      │  └ ▶ mais recente   │
│ Pastas   │                      │  ┌ resposta inline ┐│
│  locais  │                      │  │ (r)        ⌘↩  ││
├──────────┴──────────────────────┴─────────────────────┤
│ rodapé: toast de ação · indexação · sem resposta sua  │
└───────────────────────────────────────────────────────┘
```

- **Três visões no topo**, trocadas por `⌘1` Mail, `⌘2` Calendário, `⌘3` Pessoas (Contatos e Organizações). Mesma janela; a lateral muda com a visão.
- **Agenda de hoje** aparece também como faixa recolhível no topo da Lista do Mail (próximos 3 eventos), para não precisar trocar de visão o tempo todo.

## Fluxos

### Ler
- `j`/`k` percorrem a Lista; a Conversa da direita acompanha. `Enter` leva o foco para a Conversa (rola com `j`/`k` entre mensagens), `Esc` volta.
- Abrir marca como lida. `u` desfaz.
- A Conversa abre rolada na mensagem **mais recente**, com as anteriores recolhidas em uma linha cada (remetente · prévia · hora). `o` expande/recolhe a mensagem em foco; `⇧O` expande todas.
- Texto citado dentro de uma mensagem fica recolhido ("··· citação") porque a Conversa já mostra o histórico.
- Ramo: as mensagens de um ramo têm a borda lateral laranja e recuo. Clicar em "em resposta a" rola até a mãe.

### Responder
- `r` abre o **editor inline** no fim da Conversa, já com Para/Cc preenchidos (todos) e o cursor no texto. `⌘R` o mesmo, só ao remetente. `f` encaminha.
- Destinatários são **chips** com autocompletar (histórico + Contatos); `Tab` sai do campo.
- Assinatura entra sozinha no fim do texto novo, acima da citação.
- `⌘↩` envia; `⌘⇧↩` envia e arquiva. `Esc` com texto digitado pergunta "descartar rascunho?" (único "tem certeza" permitido, porque perde trabalho).
- Depois de enviar: toast "Enviada · desfazer (z) por 10 s" (atraso de envio). A Lista avança.

### Triar
- `e` arquiva, `#` apaga, `v` move para Pasta local, `h` adia (menu: amanhã 9h / semana que vem / data), `s` sinaliza, `!` marca Importante à mão.
- Todas avançam para o próximo item e mostram toast com desfazer.
- **Triagem** (lateral) é a visão do Ruído ainda não confirmado: cada cartão tem a Justificativa em uma linha e `y` confirma / `n` discorda (abre campo de Explicação em linguagem natural, que vira Regra).

### Buscar
- `/` foca a busca. Resultados substituem a Lista, com os termos destacados. `Esc` limpa.
- Operadores: `from:`, `to:`, `org:`, `has:attachment`, `before:`, `after:`, `in:<pasta local>`.

### Calendário (`⌘2`)
- Semana por padrão; `d`/`w`/`m` trocam dia/semana/mês; `t` hoje; `←`/`→` navegam.
- Agenda Microsoft editável; Agenda do Mac só leitura (cor mais clara, cadeado no evento).
- Convite recebido por e-mail: na Conversa aparece o cartão do evento com Aceitar / Recusar / Talvez; aceitar atualiza a Agenda Microsoft.
- `n` cria evento na Agenda Microsoft; na Conversa, `⇧N` cria evento com o assunto e os participantes da mensagem.
- Duplo clique num horário vazio cria evento ali. Arrastar move (de 15 em 15 min, troca de dia na semana); a borda de baixo estica a duração.
- Clique no evento abre o detalhe: Entrar na reunião, convidados com a resposta de cada um, Editar e Apagar (evento que se repete pergunta "só este" ou "toda a série").
- Lateral: mini calendário, calendários com cor (liga/desliga) e a lista de hoje com o botão Entrar.
- Enviar disponibilidade (barra do Calendário, botão na Conversa, menu do Contato em Pessoas, `⌘K`): horários livres em botões; clique tira ou devolve um horário; Enviar manda o e-mail. A lateral lista as enviadas (aguardando / confirmada).
- Entrar: Teams de trabalho abre no app; botão direito tem "abrir no navegador" e "copiar link".

### Pessoas (`⌘3`)
- Lista de Organizações (por domínio), cada uma com Contatos e todas as mensagens. `⌘3` com uma mensagem aberta vai direto para a Organização do remetente.

| Tecla | Ação | | Tecla | Ação |
|---|---|---|---|---|
| `j` `k` | próxima / anterior | | `r` | Responder (a todos) |
| `Enter` `Esc` | entrar / sair da Conversa | | `⌘R` | Responder ao remetente |
| `o` `⇧O` | expandir mensagem / todas | | `f` | Encaminhar |
| `e` | Arquivar | | `c` `⌘N` | nova mensagem |
| `#` | Apagar | | `⌘↩` `⌘⇧↩` | enviar / enviar e arquivar |
| `v` | Pasta local | | `z` | desfazer |
| `h` | Adiar | | `/` | buscar |
| `u` | lida / não lida | | `⌘K` | paleta de comandos |
| `s` | sinalizar | | `?` | atalhos |
| `y` `n` | aceitar / discordar da Sugestão | | `⌘1` `⌘2` `⌘3` | Mail / Calendário / Pessoas |

## O que muda no app de hoje (ordem)

1. Responder inline no fim da Conversa, no lugar do sheet; foco no texto; assinatura; chips de destinatário com autocompletar.
2. Avançar sozinho depois de `e` `#` `v`; toast com desfazer (`z`); atraso de envio de 10 s.
3. Conversa abre na mais recente, anteriores recolhidas; citação recolhida dentro da mensagem.
4. `⌘K`, `?`, e as três visões (`⌘1/2/3`) com o Calendário.
5. Triagem, Sugestão, Justificativa, Regra (camada de IA).
