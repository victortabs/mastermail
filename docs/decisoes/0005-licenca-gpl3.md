# 0005 — Licença GPL-3.0

- **Data:** 2026-10-13
- **Status:** aceita

## Contexto
Um dos diferenciais é garantir que o app não possa ser vendido nem fechado.

## Opções consideradas
1. GPL-3.0.
2. MIT.
3. Apache-2.0.

## Decisão
GPL-3.0-or-later.

## Consequências
- Forks distribuídos continuam abertos.
- Dependências precisam ser compatíveis com a GPL (MSAL é MIT: ok).
- A Mac App Store tem atritos históricos com a GPL; a distribuição direta com Developer ID resolve, se for preciso.
